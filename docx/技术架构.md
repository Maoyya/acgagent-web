# 前端技术架构

## 1. 技术选型

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 框架 | Vue | 3.5.x | Composition API + `<script setup>` |
| 语言 | TypeScript | 6.x | strict 模式 |
| 构建工具 | Vite | 8.x | 开发服务器 + 生产构建 |
| 路由 | Vue Router | 5.x | History 模式，路由守卫鉴权 |
| 状态管理 | Pinia | 3.x | Setup 函数式 Store |
| UI 组件库 | Element Plus | 2.x | 桌面端组件库 |
| HTTP 客户端 | Axios | 1.x | JWT 拦截器封装 |
| 图标 | @element-plus/icons-vue | 2.x | Element Plus 官方图标 |

## 2. 整体架构

### 系统分层

```

   │
   ▼
┌─────────────────────────────────────────┐

│                                          │
│  ┌──────────┐  ┌──────────┐             │
│  │  Views    │  │ Layouts  │  页面层      │
│  │  (页面)   │  │ (布局)   │             │

│       │              │                   │
│  ┌────▼──────────────▼─────┐            │

│  │    (公共组件)            │             │
│  └────────────┬────────────┘            │
│               │                          │
│  ┌────────────▼────────────┐            │
│  │  Composables / Stores   │  逻辑层     │
│  │  (组合式函数 / 状态管理)  │             │
│  └────────────┬────────────┘            │
│               │                          │
│  ┌────────────▼────────────┐            │
│  │  API / Utils / Types    │  基础层      │
│  │  (接口 / 工具 / 类型)    │             │
│  └────────────┬────────────┘            │
└───────────────┼──────────────────────────┘
                │
                ▼ HTTP (Vite Proxy /api → localhost:8080)
┌───────────────────────────────────────────┐
│  Spring Boot 后端 (acgAgent)               │
│  端口 8080，JWT 认证，REST + SSE            │

```

### 通信链路

```
浏览器 ↔ Vite Dev Server(:5173) ↔ [proxy /api] ↔ Spring Boot(:8080) ↔ MySQL(:3306)
```

生产环境由后端或 Nginx 处理 CORS 和反向代理，前端为纯静态文件。

## 4. 核心模块设计

### 4.1 HTTP 请求层（src/utils/request.ts）

Axios 实例封装，职责：

- **请求拦截器**：从 localStorage 读取 `accessToken`，附加到 `Authorization: Bearer {token}`
- **响应拦截器**：解包后端 `{code, message, data}` 信封格式；`code !== 200` 时弹出 Element Plus 错误提示
- **401 处理**：清除本地 Token，跳转登录页

```
请求发出 → 附加 JWT → 后端处理 → 响应 {code, message, data}
                                          │
                                    code === 200 → 返回 data
                                    code === 401 → 清除 Token → 跳转 /login
                                    其他 → ElMessage.error → reject
```

### 4.2 认证状态（src/stores/auth.ts）

Pinia Setup Store，职责：

- 管理 `accessToken`、`refreshToken`、`isLoggedIn` 状态
- Token 持久化到 localStorage，刷新页面不丢失
- 提供 `login()`、`register()`、`refresh()`、`logout()` 方法
- `logout()` 自动跳转到登录页

### 4.3 路由守卫（src/router/index.ts）

`beforeEach` 全局守卫逻辑：

```
访问需要认证的页面（meta.requiresAuth = true）
   │
   ├── localStorage 有 accessToken → 放行
   │
   └── 无 Token → 重定向到 /login?redirect=原路径

访问登录/注册页
   │
   ├── 已有 Token → 重定向到首页（避免重复登录）
   │
   └── 无 Token → 正常显示
```

### 4.4 布局系统

```
登录/注册页 → 独立布局（无导航栏）
其他页面    → DefaultLayout
              ┌──────────────────────────────────┐
              │ Logo  │ 项目 │ 素材库 │      退出 │  ← el-header
              ├──────────────────────────────────┤
              │                                  │
              │         <router-view />          │  ← el-main
              │                                  │
              └──────────────────────────────────┘
```

## 5. 类型系统

所有后端交互的数据类型定义在 `src/types/` 下：

| 文件 | 内容 |
|------|------|
| `api.ts` | `Result<T>` — 后端统一响应体 |
| `auth.ts` | `LoginRequest`、`RegisterRequest`、`TokenVO`、`RefreshTokenRequest` |
| `agent.ts` | `AgentVO`、`CreateAgentRequest` |
| `chat.ts` | `ConversationVO`、`MessageVO`、`CreateConversationRequest`、`SendMessageRequest` |

API 函数返回类型为 `AxiosResponse<Result<T>>`，调用方通过 `res.data.data` 获取业务数据。

## 6. API 模块

每个业务域一个文件，函数命名约定：

| 前缀 | 用途 | 示例 |
|------|------|------|
| `get` / `list` | 查询 | `getAgentList()`、`getAgent(id)` |
| `create` | 创建 | `createAgent(data)` |
| `update` | 更新 | `updateAgent(id, data)` |
| `delete` | 删除 | `deleteAgent(id)` |

新增后端接口时：先在 `src/types/` 加类型 → 再在 `src/api/` 加请求函数 → 页面调用。

## 7. 后端对接约定

| 约定项 | 说明 |
|--------|------|
| 响应格式 | 所有接口返回 `{code: number, message: string, data: T}` |
| 认证方式 | JWT Bearer Token，通过 `Authorization` 请求头传递 |
| Token 存储 | `accessToken`（2h 有效期）+ `refreshToken`（7d 有效期）存 localStorage |
| SSE 流式 | `POST /api/chat/conversations/:id/send` 返回 `text/event-stream` |
| API 前缀 | 所有接口以 `/api` 开头 |
| 代理配置 | 开发环境 Vite 将 `/api` 代理到 `http://localhost:8080` |

## 8. 构建与部署

### 开发环境

```bash
npm run dev          # 启动 Vite 开发服务器（:5173），自动代理到后端
npm run type-check   # TypeScript 类型检查
```

### 生产构建

```bash
npm run build        # vue-tsc 类型检查 + vite build → dist/
npm run preview      # 本地预览 dist/ 产物
```

构建产物为纯静态文件（HTML + JS + CSS），部署到任意 Web 服务器或 CDN 即可。生产环境需配置 Nginx 反向代理将 `/api` 请求转发到后端服务。
