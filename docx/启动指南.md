# ACG Agent Web 启动指南

## 项目简介

ACG Agent Web 是 AI 视频创作工坊的前端应用。用户输入故事梗概，AI 自动完成剧情扩展、分镜生成、角色设计、图片生成和视频生成五个步骤。

**技术栈：** Vue 3 + TypeScript + Vite 8 + Element Plus + Pinia + Vue Router

---

## 环境要求

| 依赖 | 最低版本 | 说明 |
|------|---------|------|
| Node.js | 18+ | 推荐 LTS 版本 |
| npm | 9+ | 随 Node.js 安装 |
| 后端服务 | — | Spring Boot 应用（acgAgent），需运行在 `localhost:8080` |

## 快速启动

### 1. 克隆仓库

```bash
git clone <仓库地址>
cd acgagent-web
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动后端服务

确保 Spring Boot 后端（acgAgent）已启动并运行在 `http://localhost:8080`。

前端开发服务器通过 Vite 代理将 `/api` 请求转发到后端，无需额外配置。

### 4. 启动开发服务器

```bash
npm run dev
```

启动后访问 **http://localhost:5173**。

### 5. 登录使用

1. 访问首页会自动跳转到登录页
2. 使用已有账号登录，或点击注册新账号
3. 登录后进入 Dashboard 主页面

## 核心配置

### API 代理

`vite.config.ts` 中配置了开发代理：

```
/api → http://localhost:8080
```

所有前端请求以 `/api` 开头，由 Vite 自动转发到后端。如需修改后端地址，编辑 `vite.config.ts` 中的 `proxy.target`。

### 认证机制

- **方式：** JWT Bearer Token
- **存储：** `localStorage`（`accessToken`、`refreshToken`）
- **自动处理：** `src/utils/request.ts` 的请求拦截器自动附加 Token，响应拦截器处理 401 自动跳转登录

### SSE 流式通信

聊天消息使用 SSE（Server-Sent Events）流式传输，由 `src/composables/useSSE.ts` 封装，基于原生 `fetch` + `ReadableStream` 实现。

## 生产部署

```bash
# 构建生产包
npm run build
```

构建产物输出到 `dist/` 目录。部署时需要：

1. 将 `dist/` 目录部署到 Web 服务器（如 Nginx）
2. 配置 Web 服务器反向代理：将 `/api` 请求转发到 Spring Boot 后端地址
3. 配置 HTML5 History 模式回退：所有非静态资源请求返回 `index.html`

**Nginx 参考配置：**

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist;
    index index.html;

    # API 反向代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # Vue Router History 模式
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 常见问题

### 启动后页面空白 / 接口报错

确认后端服务已启动且运行在 `http://localhost:8080`。检查浏览器控制台网络请求是否正常。

### 登录后 Token 丢失

Token 存储在 `localStorage`，清除浏览器缓存或使用无痕模式会导致需要重新登录。

### 修改后端地址

编辑 `vite.config.ts` 中的 `server.proxy` 配置：

```typescript
proxy: {
  '/api': {
    target: 'http://your-backend-host:port',
    changeOrigin: true,
  }
}
```
