# 前端业务流程

## 1. 用户认证流程

### 1.1 注册流程

```
用户访问 /register
   │
   ▼
填写用户名 + 密码 + 邮箱（选填）
   │
   ▼
前端表单校验（用户名/密码必填）
   │
   ▼
POST /api/auth/register {username, password, email}
   │
   ├── 成功（code=200）→ 后端返回 accessToken + refreshToken
   │                     → 存入 localStorage
   │                     → 更新 Pinia auth store
   │                     → 跳转首页 /
   │
   └── 失败 → ElMessage 提示错误信息（如用户名已存在）
```

### 1.2 登录流程

```
用户访问 /login
   │
   ▼
填写用户名 + 密码
   │
   ▼
POST /api/auth/login {username, password}
   │
   ├── 成功 → 存储 Token → 跳转 redirect 参数指定页面或首页
   │
   └── 失败 → ElMessage 提示（用户名或密码错误）
```

### 1.3 Token 刷新流程

```
请求拦截器检测到 accessToken
   │
   ▼
发送请求 → 后端返回 401（Token 过期）
   │
   ▼
响应拦截器捕获 401
   │
   ▼
POST /api/auth/refresh {refreshToken}
   │
   ├── 成功 → 更新 localStorage 中的 Token → 重试原请求
   │
   └── 失败（refreshToken 也过期）→ 清除 Token → 跳转 /login
```

### 1.4 登出流程

```
用户点击「退出」
   │
   ▼
authStore.logout()
   ├── 清除 localStorage（accessToken、refreshToken）
   ├── 重置 Pinia 状态（isLoggedIn = false）
   └── 路由跳转 /login
```

## 2. 项目管理流程

### 2.1 查看项目列表

```
用户访问 /（需登录）
   │
   ▼
页面加载 → 请求项目列表接口
   │
   ▼
展示项目卡片网格（按更新时间倒序）
   │
   ├── 有项目 → 显示项目卡片列表
   │              每张卡片：标题、故事梗概摘要、进度状态、更新时间
   │
   └── 无项目 → 空状态引导："还没有创作项目，点击右上角开始你的第一个故事吧"
```

### 2.2 创建项目

```
用户点击「创建项目」→ 跳转 /project/create
   │
   ▼
填写表单
   ├── 项目标题（必填，≤ 200 字）
   └── 故事梗概（必填，≤ 5000 字）
   │
   ▼
提交创建 → 后端创建项目
   │
   ▼
跳转到创作工坊 /project/:id，进入 Step 1
```

## 3. 创作工坊流程

创作工坊是核心页面，采用 5 步向导模式。每一步用户都可以查看、编辑、重新生成和确认。

### 整体流程

```
创建项目 → Step 1: 剧情扩展 → Step 2: 分镜生成 → Step 3: 角色设计
         → Step 4: 图片生成 → Step 5: 视频生成 → 完成
```

### 3.1 Step 1：剧情扩展

```
用户进入 /project/:id
   │
   ▼
页面展示：顶部步骤导航 + 左右分栏
   │
   ▼
左侧：用户原始故事梗概（只读）
右侧：AI 流式生成剧情（SSE 打字机效果）
   │
   ├── 生成中 → 显示 loading + 文字逐字出现
   ├── 生成完成 → 用户可编辑文本框中的剧情内容
   │
   ▼
用户操作选择：
   ├── 「重新生成」→ 再次请求 AI 生成（不覆盖当前内容，可对比）
   └── 「确认剧情，进入下一步」→ 调用确认接口 → 进入 Step 2
```

**SSE 流式交互细节：**

```
前端发送 POST /api/chat/conversations/:id/send {content: 故事梗概}
   │
   ▼
后端返回 Content-Type: text/event-stream
   │
   ▼
前端使用 fetch + ReadableStream 逐块读取
   │
   ├── 收到 data: {"content": "一段文字"} → 追加到文本框
   ├── 收到 data: {"content": "更多文字"} → 继续追加
   └── 收到 data: [DONE] → 流结束，保存完整内容
```

### 3.2 Step 2：分镜生成

```
基于 Step 1 确认的剧情
   │
   ▼
AI 生成多个分镜卡片
   │
   ▼
左侧：分镜卡片列表（垂直排列）
   每张卡片：场景序号 + 镜头序号 + 描述摘要 + 时长 + 镜头运动标签
   │
   ▼
点击卡片 → 右侧展示详细编辑面板
   可编辑字段：镜头描述、镜头运动（下拉选择）、时长、对白、旁白
   │
   ▼
用户操作：
   ├── 编辑单个分镜字段 → 自动保存
   ├── 删除不需要的分镜
   ├── 「重新生成分镜」→ 全部重新生成
   └── 「确认分镜，进入下一步」→ 进入 Step 3
```

### 3.3 Step 3：角色设计

```
基于 Step 1 确认的剧情，AI 自动提取角色
   │
   ▼
左侧：角色卡片网格（2 列）
   每张卡片：角色名 + 外貌描述摘要
   │
   ▼
点击卡片 → 右侧详细编辑面板
   可编辑字段：角色名、外貌描述、服装描述、性格特征
   │
   ▼
用户操作：
   ├── 编辑角色信息
   ├── 删除不需要的角色
   ├── 「重新生成角色」→ 全部重新生成
   └── 「确认角色，生成图片 →」→ 进入 Step 4
```

### 3.4 Step 4：图片生成

```
基于 Step 3 角色 + Step 2 分镜，AI 生成图片
   │
   ▼
左侧：图片网格（3 列）
   分类 Tab：[角色三视图] [分镜场景图]
   每张图片：缩略图 + 标签 + 状态（生成中/已完成/失败）
   │
   ▼
点击图片 → 右侧放大预览
   │
   ▼
单张图片操作：
   ├── 「重新生成」→ 单张重新生成
   └── 「✓ 确认」→ 标记该图片满意
   │
   ▼
全部确认后 → 「全部确认，生成视频 →」→ 进入 Step 5
```

### 3.5 Step 5：视频生成

```
基于 Step 4 确认的图片，Seedance 2.0 生成视频
   │
   ▼
左侧：视频列表
   每项：分镜序号 + 描述摘要 + 状态标签 + 进度条
   │
   ▼
点击列表项 → 右侧视频播放器切换播放
   │
   ▼
单项操作：
   ├── 「重新生成」→ 单个视频重新生成
   └── 「⬇ 下载」→ 下载视频到本地
   │
   ▼
全部完成 → 「下载全部」→ 项目标记为「已完成」
```

## 4. 素材库流程

```
用户访问 /assets（需登录）
   │
   ▼
请求用户的素材列表
   │
   ▼
展示素材网格
   筛选条件：[全部] [图片] [视频] + 项目下拉筛选
   │
   ▼
素材操作：
   ├── 点击 → 放大预览 / 视频播放
   ├── 「下载」→ 单个素材下载到本地
   └── 「删除」→ 确认弹窗 → 删除素材
   │
   ▼
空状态："完成一个视频项目后，生成的素材会出现在这里"
```

## 5. 页面状态管理

### 5.1 项目状态流转

```
草稿 → 剧情扩展中 → 分镜生成中 → 图片生成中 → 视频生成中 → 已完成
 │        │              │              │              │            │
 │        └────── 用户可回退到任意已完成步骤编辑 ──────┘            │
 │                                                                │
 └───────── 修改已完成步骤后，需重新确认后续步骤 ─────────────────┘
```

### 5.2 页面刷新恢复

```
用户在工坊页面刷新
   │
   ▼
路由守卫通过（有 Token）
   │
   ▼
页面加载 → 请求项目详情（包含当前步骤状态）
   │
   ▼
根据步骤状态恢复到对应 Step
   ├── 自动跳转到上次停留的步骤
   └── 已完成步骤的数据从后端重新加载
```
