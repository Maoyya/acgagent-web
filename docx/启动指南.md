# ACG Agent Web 启动指南

## 项目简介

ACG Agent Web 是 AI 视频创作工坊的前端应用。用户输入故事梗概，AI 自动完成剧情扩展、分镜生成、角色设计、视频生成等步骤。系统同时提供 Agent 管理、RBAC 权限管理、悬浮式 AI 对话等后台能力。

**技术栈：** Vue 3 + TypeScript + Vite 8 + Element Plus + Pinia + Vue Router

> 注：创作工坊与素材库当前为前端原型（Mock），后端接入进行中；认证、Agent 管理、RBAC、个人中心、悬浮聊天已对接后端。

## 快速启动

### 1. 克隆仓库

```bash
git clone <仓库地址>
cd acgagent-web
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动后端服务

确保 Spring Boot 后端（acgAgent）已启动并运行在 `http://localhost:8080`。前端开发服务器通过 Vite 代理将 `/api` 请求转发到后端，无需额外配置。

### 4. 启动开发服务器

```bash
npm run dev
```

启动后访问 **http://localhost:5173**。

### 5. 登录使用

1. 访问首页，未登录会自动跳转到登录页
2. 使用已有账号登录，或点击注册新账号（用户名 5~50、密码 6~256、邮箱选填）
3. 登录后落地 **Dashboard 概览页**；管理员额外可见 Agent 管理、系统管理菜单

## 核心配置

### API 代理

`vite.config.ts` 中配置了开发代理：

```
/api → http://localhost:8080
```

所有前端请求以 `/api` 开头，由 Vite 自动转发到后端。如需修改后端地址，编辑 `vite.config.ts` 中的 `proxy.target`。

### 认证机制

- **方式：** JWT Bearer Token
- **存储：** `localStorage`（`accessToken`、`refreshToken`）
- **请求附加：** `src/utils/request.ts` 请求拦截器自动附加 Token
- **过期处理：**
  - 路由守卫（`src/router/index.ts`）依据 JWT `exp` 提前拦截过期 Token，过期则清登录态跳 `/login`
  - 响应拦截器在收到 401 时清除 Token 并跳转登录（当前未做 refresh 重试）

### 流式通信

对话流式输出由 `src/composables/useSSE.ts` 封装，基于原生 `fetch` + `ReadableStream`（非 EventSource），对接 `POST /api/chat/conversations/:id/send`。

## 页面路由

| 路径 | 页面 | 需登录 | 备注 |
|------|------|--------|------|
| `/login` | 登录 | 否 | 已登录访问会跳 `/dashboard` |
| `/register` | 注册 | 否 | 同上 |
| `/` | — | 是 | 重定向到 `/dashboard` |
| `/dashboard` | 概览 | 是 | 登录后落地页 |
| `/agents` | Agent 管理 | 是 | 仅 admin（`meta.roles: ['admin']`） |
| `/workshop/:id` | 创作工坊 | 是 | 当前 Mock |
| `/assets` | 素材库 | 是 | 当前 Mock |
| `/profile` | 个人中心 | 是 | |
| `/system/users` | 用户管理 | 是 | 仅 admin |
| `/system/roles` | 角色管理 | 是 | 仅 admin |
| `/system/permissions` | 权限管理 | 是 | 仅 admin |

> 对话功能通过全局悬浮面板（ChatBubble + ChatPanel）承载，**无独立 `/chat` 路由**（`views/chat/List·Detail` 未挂载）。

未登录或 Token 过期访问需鉴权页面，会自动跳转 `/login?redirect=原路径`，登录后返回原页面。

## 生产部署

```bash
npm run build
```

构建产物输出到 `dist/` 目录。部署时需要：

1. 将 `dist/` 目录部署到 Web 服务器（如 Nginx）
2. 配置 Web 服务器反向代理：将 `/api` 请求转发到 Spring Boot 后端地址
3. 配置 HTML5 History 模式回退：所有非静态资源请求返回 `index.html`

**Nginx 参考配置：**

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist;
    index index.html;

    # API 反向代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # Vue Router History 模式
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 常见问题

### 启动后页面空白 / 接口报错

确认后端服务已启动且运行在 `http://localhost:8080`。检查浏览器控制台网络请求是否正常。

### 登录后 Token 丢失 / 过期跳登录

Token 存储在 `localStorage`，清除浏览器缓存或使用无痕模式会需要重新登录。Token 过期后路由守卫会自动跳转登录页（依据 JWT `exp`）。

### 修改后端地址

编辑 `vite.config.ts` 中的 `server.proxy` 配置：

```typescript
proxy: {
  '/api': {
    target: 'http://your-backend-host:port',
    changeOrigin: true,
  }
}
```
